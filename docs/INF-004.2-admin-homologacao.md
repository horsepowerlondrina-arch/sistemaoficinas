# INF-004.2 — Painel administrativo na homologação

O caminho `/admin` é habilitado em desenvolvimento local. Em builds publicados, ele exige as duas variáveis Vite abaixo e uma correspondência exata entre o hostname atual e a lista autorizada:

- `VITE_PLATFORM_ADMIN_ENABLED=true`
- `VITE_PLATFORM_ADMIN_ALLOWED_HOSTS=sistema-oficinas-homologacao.vercel.app`

Configure esses valores somente no projeto Vercel `sistema-oficinas-homologacao`, no ambiente Production desse projeto. Eles são opções públicas incluídas no bundle, não segredos. O hostname também é verificado no navegador para impedir que uma configuração copiada para outro domínio habilite a tela.

A disponibilidade da página não autentica o administrador. A API administrativa mantém cookie, sessão, permissões e MFA próprios, separados da autenticação das oficinas. O acesso continua exigindo conta administrativa ativa e senha com código TOTP.
