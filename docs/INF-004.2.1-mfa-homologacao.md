# INF-004.2.1 — MFA temporariamente opcional para a conta fictícia

Na homologação, somente a conta `admin@plataforma.local` pode entrar apenas com senha. O servidor exige simultaneamente `VERCEL=1`, `VERCEL_ENV=production`, o e-mail configurado em `PLATFORM_ADMIN_TEST_MFA_BYPASS_EMAIL` e o hostname exato definido em `PLATFORM_ADMIN_TEST_MFA_BYPASS_HOST`. A tela oculta o campo de código apenas para esse e-mail.

Configure as variáveis somente no projeto Vercel `sistema-oficinas-homologacao`, no ambiente Production:

- `PLATFORM_ADMIN_TEST_MFA_BYPASS_EMAIL=admin@plataforma.local`
- `PLATFORM_ADMIN_TEST_MFA_BYPASS_HOST=sistema-oficinas-homologacao.vercel.app`
- `VITE_PLATFORM_ADMIN_TEST_MFA_BYPASS_EMAIL=admin@plataforma.local`

Contas diferentes continuam exigindo TOTP. Se o teste enviar um código, o servidor ainda o valida. O login por senha gera o evento de auditoria `admin.login.mfa_test_bypass`, além do evento normal `admin.login`. Convites e configuração inicial de administradores continuam exigindo TOTP.

Para restaurar a exigência do segundo fator para a conta de teste, remova as três variáveis do projeto e gere um novo deployment. Não é necessário alterar registros, senhas ou segredos MFA no banco.
